# Polices

Hébergées sur le site (plus de connexion à Google Fonts), jeu de caractères « latin » de Google Fonts
(français compris : accents, œ, « », espaces fines, €). Polices variables : un fichier couvre toutes les graisses.

| Fichier | Police | Source | Licence |
|---|---|---|---|
| `big-shoulders-display-latin.woff2` | Big Shoulders Display (variable, 100–900) | Google Fonts, v24 (fonts.gstatic.com) | SIL Open Font License 1.1 : `OFL-big-shoulders-display.txt` |
| `manrope-latin.woff2` | Manrope (variable, 200–800) | Google Fonts, v20 (fonts.gstatic.com) | SIL Open Font License 1.1 : `OFL-manrope.txt` |

Copyright 2019 The Big Shoulders Project Authors (https://github.com/xotypeco/big_shoulders).
Copyright 2018 The Manrope Project Authors (https://github.com/googlefonts/manrope).
Récupérées le 27/10/2026. Les polices de repli (« Manrope repli », « Big Shoulders repli » dans style.css) sont des polices
du système (Arial, Arial Narrow) mises aux mêmes dimensions (size-adjust…) pour que la page ne bouge pas quand la vraie
police arrive : valeurs calculées avec fontTools sur un texte français courant.
